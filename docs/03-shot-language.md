# 电影镜头语言手册（Shot Language）

> 读者：写 Remotion 代码的 AI。画面管线：**AI 生成电影感静帧 + 程序化运镜**。
> 每个概念 = 定义 + 叙事功能 + Remotion 实现（代码/参数）。
> 写作日期：2026-10-02。调研来源：No Film School、StudioBinder 系资料、电影教材（景别/角度/运镜/剪辑语法）、社区 AI 技能库的 cinematography 规范。

## 通用实现模型（先读这段）

Remotion 里没有真实摄影机。每个"镜头" = **一张 AI 静帧 + 一个取景窗动画**：

```tsx
// 通用 <Shot>：在一张大图上做取景窗动画（起始窗 → 结束窗）
type Window = { x: number; y: number; scale: number }; // x,y = 取景中心偏移（像素，相对画布中心），scale = 放大倍数
const Shot: React.FC<{ src: string; from: Window; to: Window; dur: number; ease?: (t:number)=>number }> = ...
```

实现方式：`overflow: hidden` 的 `AbsoluteFill` 里放一张**大于画布**的图，
每帧 `transform: translate(-x, -y) scale(s)`。`x/y/s` 全部由 `interpolate(frame, …)` 推导，
配 easing。全片所有运镜都走这一个模型，只是参数不同。

**分辨率铁律**：取景窗 zoom 到 N 倍时，源图有效分辨率 = 源图宽度 / N。
要在 1080p 成片里保持清晰，`源图宽度 ≥ 1920 × 最大 zoom`。
AI 生图通常 2048px 宽 → 安全 zoom 上限约 **2.0×**（特写可用 2.2×，颗粒和暗角会掩盖轻微发虚；
大特写 3× 以上必然发虚——要么接受"柔焦细节"的质感，要么把大特写单独生一张细节图）。

## 一、景别（Shot Sizes）：离多近 = 多亲密

**原理**：景别是"观众和被摄体的心理距离"。越近 = 越亲密/越主观；越远 = 越客观/越有史诗感。
科普片的铁律：**信息密度和景别成反比**——讲概念用远景，讲情绪/细节用特写。

| # | 景别 | 英文 | 画面定义 | 叙事功能（什么时候用） | Remotion 实现（2048px 源图，1920×1080 画布） |
|---|------|------|----------|------------------------|----------------------------------------------|
| 1 | 大远景 | Extreme Long Shot (ELS/XLS) | 主体只是风景中的一个点，甚至看不见人 | 建立时空："这是哪里、什么时代"；表现渺小、孤独、史诗感。每幕开场用 | scale 1.0，取整图；取景中心 = 画面中心。慢推 1.0→1.06 营造"进入"感 |
| 2 | 远景 | Long Shot / Wide Shot (WS) | 人物全身入画，头顶脚下留白，环境占主导 | 交代人物与环境的关系；动作场面（火车奔驰、战场） | scale 1.15–1.3，取景中心对准主体 |
| 3 | 全景 | Full Shot (FS) | 人物从头到脚**充满**画面，强调动作而非情绪 | 展示动作过程（耕作、锻造、舞蹈） | scale 1.4–1.6，主体居中或三分点 |
| 4 | 中景 | Medium Shot (MS) | 腰部以上，对话和叙事的默认景别 | 讲"正在发生什么"：人物 + 一点环境，最常用的叙事景别 | scale 1.7–1.9，主体放在左右三分点，视线方向留白 |
| 5 | 近景 | Medium Close-Up (MCU) | 胸部以上 | 偏重人物，环境退后；观点陈述、强调人物状态 | scale 2.0–2.2 |
| 6 | 特写 | Close-Up (CU) | 面部充满画面（或物体的重要局部） | 情绪、反应、关键证据；"观众必须看这里" | scale 2.2–2.6，取景中心 = 面部/物体中心；**必须单独生图或确认源图分辨率够** |
| 7 | 大特写 | Extreme Close-Up (ECU) | 眼睛、一只手、一枚齿轮、火焰的一簇 | 极致强调：细节即信息（压力表指针、甲骨文笔画、火星） | scale 2.8–3.5，**单独生一张细节图**（prompt 写 "extreme close-up of …"），不要硬 zoom |

**景别跳跃规则**（剪辑时用，见第五节 30 度规则）：相邻两个镜头，景别差**一级**最顺滑
（WS→MS→CU），差两级是"跳一下"的强调（WS→CU，慎用），差三级以上（WS→ECU）观众会出戏——
除非中间用运镜（push in）一气呵成地连起来。

**AI 生图提示词里的景别词**（直接写进 prompt，比后期 zoom 更真）：
`extreme wide establishing shot` / `wide shot, full body` / `medium shot, waist up` /
`close-up portrait` / `extreme close-up detail of …`。**同一幕需要多个景别时，为每个景别单独生图**，
不要指望一张图 zoom 出所有景别（分辨率和透视都不对）。

```tsx
// 景别预设表（相对 1920×1080 画布，源图 2048px）
export const SHOT_SCALE = {
  ELS: 1.0,   // 整图
  WS: 1.25,   // 远景
  FS: 1.5,    // 全景
  MS: 1.8,    // 中景
  MCU: 2.05,  // 近景
  CU: 2.4,    // 特写（单独生图更佳）
  ECU: 3.2,   // 大特写（必须单独生图）
} as const;
```

## 二、角度（Camera Angles）：谁在看 = 权力关系

**原理**：角度和景别独立——角度回答"摄影机在**多高**、**歪不歪**"，编码的是**权力与心理状态**，
而不是距离。同一中景，仰角拍出来是英雄，俯角拍出来是囚徒。

| 角度 | 英文 | 定义 | 叙事含义 | 什么时候用（科普片） | Remotion 实现 |
|------|------|------|----------|----------------------|---------------|
| 平视 | Eye level | 镜头与被摄体视线等高 | 中立、客观、可信；观众和被摄体"平起平坐" | **默认角度**，占全片 70% 以上；解说性内容 | 不做任何处理，取景窗水平 |
| 仰角 | Low angle | 镜头在下，向上看 | 权力、威严、压迫感、英雄感；被摄体"高大" | 金字塔、火箭发射、巨浪、领袖、纪念碑；"人类征服 X"的段落 | **生图时预埋**：prompt 加 `low angle shot, looking up at …`；Remotion 里再加缓慢上摇（取景窗 y 从下往上 0→-60px）强化 |
| 俯角 | High angle | 镜头在上，向下看 | 脆弱、渺小、被审视；"上帝视角"的疏离 | 表现灾难中的人类、显微镜下的样本、被观察的实验体 | **生图时预埋**：`high angle shot, looking down at …`；Remotion 里缓慢下摇 |
| 鸟瞰 | Bird's-eye / Top-down | 正上方垂直向下 | 地理、格局、 patterns；抽离情绪，纯理性 | 地图、城市、星系、迁徙路线、"从太空看地球" | 必须生图预埋（`aerial top-down view`）；Remotion 里可做缓慢旋转（rotate 0→6°，极慢）表现"俯瞰流转" |
| 虫视 | Worm's-eye view | 贴近地面向上看 | 极致的敬畏/ monumental；建筑、巨物 | 仰望星空、火箭、高塔、巨树 | 生图预埋 `worm's-eye view looking up` |
| 荷兰角 | Dutch angle / Canted | 地平线倾斜 10–30° | 不安、错乱、失衡、心理紧张 | 危机、灾难预警、文明转折点；**慎用，一片最多 1–2 次** | `transform: rotate(-8deg)` + scale 1.15（盖住旋转露出的边角）；可做 0→-8° 的渐变倾斜，表现"世界正在倾斜" |
| 过肩 | Over-the-shoulder (OTS) | 从一人肩后拍另一人 | 对话、窥视、临场感 | 两个人物/文明"对峙"（如人类 vs AI）；较少用 | 生图预埋 `over-the-shoulder shot`；前景肩膀可单独做一层，微视差 |

**铁律**：角度**只能在生图时决定**，后期无法真正改变透视。分镜阶段就定好每张图的角度词，
Remotion 里只做"强化性微调"（上下取景偏移 ±60px、荷兰角旋转）。想在一个镜头里"从平视变成仰角"？
做不到——拆成两个镜头硬切（这是 30 度规则允许的：角度差足够大）。


## 三、运镜（Camera Movements）：动 = 情绪在走

**原理**：运镜方向自带语义。记住四句口诀：**推近=深入/紧张，拉远=揭示/释然，横移=巡视/经过，升降=降临/沉沦**。
速度规范：纪录片式运镜要"慢到几乎察觉不到"（3–5 秒只变 8–15%），冲击式运镜要"快到躲不开"
（10–20 帧完成）。

下表 `dur` 为典型时长，`Δ` 为变化幅度（相对画布），全部用 `interpolate(frame, [0, dur], …)` 实现：

| 运镜 | 英文 | 动作 | 叙事功能 | 参数规范 | Remotion 代码模板 |
|------|------|------|----------|----------|-------------------|
| 推 | Push in / Dolly in | 取景窗缩小（scale↑），向主体靠近 | 深入、聚焦、紧张累积；抛出核心观点时用 | 3–5s，scale 1.0→1.12–1.18，easeInOut | `scale = interpolate(f,[0,d],[1,1.15],{easing:Easing.inOut(Easing.cubic)})` |
| 拉 | Pull out | 取景窗放大（scale↓），揭示全貌 | 揭示、释然、收束；章节结尾用 | 3–4s，scale 1.15→1.0 | 同上反向；结尾可加速（easeIn）表现"豁然开朗" |
| 摇 | Pan | 取景窗水平移动（scale 不变） | 巡视、展示广度、跟随横向运动 | 3–6s，x 位移 ±10–20% 画布宽（±200–380px），线性或 easeInOut | `x = interpolate(f,[0,d],[-160,160])` |
| 移 | Truck / Tracking | 镜头横向**平移**（带视差，区别于摇） | 跟随行进（火车、迁徙、军队）；"与历史同行"感 | 4–6s；背景层慢、前景层快（视差比 1:1.6） | 两层图：`xBg = lerp(-80,80)`，`xFg = lerp(-160,160)` |
| 升 | Crane up / Tilt up | 取景窗上移（或 scale 微增模拟上升） | 崇高、降临、格局打开；开场 establishing 常用 | 4–6s，y 位移 -120px（向上看更多天空） | `y = interpolate(f,[0,d],[60,-60])` |
| 降 | Crane down / Tilt down | 取景窗下移 | 落地、 arrival、情绪下沉 | 3–5s，y 位移 +120px | 反向 |
| 跟 | Follow | 主体居中不动，背景移动 | 主体是历史进程本身（如火车头），世界在退行 | 背景层 x 匀速 -300px，主体层静止或微推 | 主体图 scale 1.0 静止 + 背景图 pan；两层叠加 |
| 环绕 | Orbit / Arc | 围绕主体做弧线 | 英雄时刻、强调、仪式感；**静帧上慎用** | 3–4s，rotate ±4° + x 弧线位移 | `rotate = interpolate(f,[0,d],[-3,3]); x = sin(progress*π)*120`；幅度小，只做"呼吸式环绕" |
| 手持 | Handheld | 细碎不规则抖动 | 纪实感、临场、 unease；灾难/战争段落 | 全程叠加：`sin` 复合波，振幅 4–8px，频率 0.5–1.2Hz | `dx = 6*sin(t*3.1)+3*sin(t*7.7)`；**只用于特定段落**，日常不用 |
| 甩镜 | Whip pan | 12–20 帧内横向甩过全画布 | 转场：时间跳跃、段落切换；能量爆发 | 14–18 帧，x 位移 ±120% 画布宽，easeIn；加动态模糊（复制 3 层，opacity 递减、x 错位） | 见 design-playbook 转章节；方向全片统一（只许左→右或只许右→左） |
| 冲击变焦 | Crash zoom / Punch zoom | 10–15 帧内 scale 骤增 | 震惊、揭示真相、"注意看" | 12 帧，scale 1.0→1.45，easeOut（先快后稳） | `scale = interpolate(f,[0,12],[1,1.45],{easing:Easing.out(Easing.quad)})`，落点后静止 0.5s 让观众"登记" |
| 变焦+推拉 | Dolly zoom | scale 变、取景窗反向变，主体大小不变、背景压缩/拉伸 | 经典眩晕感（希区柯克式）；时空扭曲、顿悟 | 3s：scale 1.0→1.3 同时取景窗中心反向补偿 | 静帧上效果有限，**建议只在概念段落用一次**，或直接用 AI 视频生成 |

**运镜代码骨架**（所有运镜共用，换参数即可）：

```tsx
import {interpolate, Easing, useCurrentFrame} from 'remotion';

// 取景窗：start → end，dur 帧
const f = useCurrentFrame();
const p = (a: number, b: number, ease = Easing.inOut(Easing.cubic)) =>
  interpolate(f, [0, dur], [a, b], {easing: ease, extrapolateRight: 'clamp'});

<div style={{position:'absolute', inset:0, overflow:'hidden'}}>
  <img src={staticFile(img)} style={{
    width: W * overscan, // overscan=1.6，保证取景窗移动时不露边
    transform: `translate(${cx - p(x0,x1)}px, ${cy - p(y0,y1)}px) scale(${p(s0,s1)})`,
    transformOrigin: 'center',
  }}/>
</div>
```

**运镜纪律**（违反即廉价，见第七节反模式）：
1. 一个镜头只做**一种**主运镜（推 + 微摇可以，推 + 拉 + 摇不行）。
2. 相邻镜头的运镜方向要有逻辑：连续两个推镜 = 不断深入（OK）；推镜接拉镜 = 情绪反转（慎用，要有叙事理由）。
3. 甩镜/冲击变焦是"标点符号"，全片 ≤3 次；日常用推/摇/静。
4. 运镜速度全片统一量级：慢镜 8–15% / 3–5s；不要一个镜头 5% 漂移、下一个 40% 猛推。


## 四、构图（Composition）：观众的眼睛往哪看，你说了算

**原理**：构图 = 在取景窗内**安排视觉重量**。观众的眼睛会先落在"权力点"上，
然后沿引导线走。好的构图让观众"毫不费力地看懂"，坏的构图让观众"不知道看哪"。

| 法则 | 定义 | 什么时候用 | AI 生图提示词预埋写法 | Remotion 内的补救 |
|------|------|-----------|----------------------|-------------------|
| 三分法 | 画面横竖三等分，主体放在 4 个交点（权力点）上 | **默认法则**，80% 镜头 | `rule of thirds, subject placed at the left third intersection` | 选图时挑主体已在三分点的；取景窗 x 偏移把主体"推"到三分点 |
| 对称式 | 主体居中，左右镜像 | 建筑、仪式、神圣、秩序；"纪念碑感" | `symmetrical composition, centered` | 居中取景，不做横向运镜（会破坏对称） |
| 框架构图 | 用门/洞/树枝在画面内再框一层 | 制造"窥视感"、空间纵深 | `framed through a doorway / cave opening / branches` | 前景框架单独一层，做慢速反向视差，纵深感极强 |
| 引导线 | 道路、河流、光束把视线引向主体 | 风景、迁徙、旅途 | `leading lines converging toward the subject` | 取景窗沿引导线方向运镜（顺着路"走进去"） |
| 前景遮挡 | 画面边缘放虚化的前景（树叶、人群剪影） | 增加纵深、临场感；"我们就在现场" | `foreground bokeh / out-of-focus foreground elements` | 前景单独一层 + 大位移视差（1.6× 速度） |
| 留白/视线方向 | 人物/运动主体**朝向**的一侧要留白 | 永远。人物看向右边，右边留白；火车向右开，右边留白 | `subject looking to the right with lead room / negative space` | 取景时把主体放在**逆**运动方向的三分点 |
| 头顶空间 | 人物头顶到画面上沿留 10–15% 画面高度 | 人物中近景 | `proper headroom`（一般模型默认会做） | 取景窗 y 微调；头顶留白太多 = 渺小/孤独（可故意用），太少 = 压迫 |
| 负空间 | 大面积留白/天空/黑暗 | 孤独、沉思、史诗、"未知" | `vast negative space, minimalist` | 配合慢推镜，负空间产生"深渊感" |

**中文科普片的构图 checklist**（每张 AI 图生成后、每镜取景前过一遍）：
1. 主体在三分点上吗？（不是 → 取景窗偏移修正）
2. 视线/运动方向有留白吗？（没有 → 换取景位置，别让人物"撞墙"）
3. 有前景层吗？（没有 → 考虑加代码粒子/暗角做人工前景）
4. 地平线在上/下三分线吗？（在正中间 → 除非对称构图，否则压到三分线）
5. 字幕区（底部）干净吗？（主体别和字幕打架 → 取景下移或选图时避开底部 1/4）

**第 5 条最重要**：我们的字幕固定在底部，AI 图的主体如果压在底部 1/4，
字幕会糊在脸上。生图 prompt 里加 `clear lower third, uncluttered bottom area for subtitles`，
或取景时整体上移。


## 五、剪辑语法（Editing Grammar）：镜头之间的法律

单个镜头是"词"，剪辑是"语法"。违反语法，观众不会觉得"有创意"，只会觉得"晕"。

### 5.1 轴线规则（180° Rule）：别让观众迷路

**定义**：两个被摄体之间有一条假想轴线（比如火车行进方向、两人对话的视线）。
所有镜头必须待在轴线的**同一侧**，否则观众的空间感会翻转。

**科普片里的主要应用——运动方向一致**：火车在第 1 镜从左向右开，第 2 镜必须还是从左向右。
一旦反了，观众会觉得"火车掉头了"。**AI 生图时就要定死方向**：prompt 写
`moving from left to right`，全片同一主体运动方向永不反转。

**Remotion 实现**：分镜表里给每幕标注 `dir: 'L→R'`；取景窗 pan 方向、粒子漂移方向、
转场甩镜方向全部与之对齐。检查方法：把全片缩略图拼成一排，运动方向应该是一条直线。

### 5.2 30 度规则（30° Rule）：换镜要有换的理由

**定义**：同一主体的相邻两个镜头，机位夹角至少差 30°（或景别差一级以上），
否则看起来像"卡了一下"的跳切（jump cut），观众会以为是 bug。

**在 AI 静帧管线下的换算**（没有真实机位，用"视觉差"代替角度差）：
- 景别差一级（MS→CU）= 天然满足 30° 要求，最安全的切法。
- 同景别换图：必须换**角度**（平视→仰角）或换**取景位置**（主体从左三分点切到右三分点）。
- **轴向切（Axial cut）是例外**：沿镜头轴线直推（WS 一镜到底推成 CU），夹角为 0 但景别巨变，
  观众读作"强调"而非"穿帮"。Remotion 里实现为一镜内的 crash zoom / 长 push in。

### 5.3 正反打（Shot / Reverse Shot）

**定义**：A 看向右 → 切 B 看向左，交替。观众自动脑补"他们在对话/对峙"。
**科普片用法**："人类 vs AI"、"过去 vs 未来"、"提问 vs 回答"的段落。
**实现**：生两张图（`person A looking right` / `person B looking left`），Sequence 交替，
每镜 2–3 秒，景别保持一致（都是 MS 或都是 CU），轴线绝不跨。

### 5.4 切入 / 切出（Cutaway / Insert）

**定义**：从主动作临时切到一个**细节**（insert：场景内的钟表/文件/手部；
cutaway：场景外的反应/环境），再切回来。功能：隐藏时间跳跃、补充信息、给观众"喘口气"。
**科普片用法**：讲"蒸汽机"时，主镜头是火车全景 → insert 压力表特写 1.5s → 回全景。
**实现**：细节图单独生（`extreme close-up of a pressure gauge`），Sequence 插 45 帧，
前后主镜头景别不变，观众感觉"时间没断"。

### 5.5 匹配剪辑（Match Cut）：最高级的转场

**定义**：两个镜头靠**形状或动作**押韵来衔接。图形匹配（圆→圆：太阳→车轮→齿轮）、
动作匹配（挥手→挥旗）、概念匹配（骨头→飞船，《2001 太空漫游》名场面）。
**科普片用法**：这是"时间线加速感"的神器——篝火的圆 → 车轮的圆 → 齿轮的圆 → 地球的圆，
四个时代一气呵成，观众起鸡皮疙瘩。
**实现**：分镜阶段就设计"押韵对"：A 镜结尾取景窗收紧到圆形主体，B 镜开场取景窗从圆形主体拉开。
两镜主体在画面中的**位置**也要重合（都用中心构图），硬切，无转场特效。

### 5.6 J-cut / L-cut：声音先行、画面断后

**定义**：J-cut = 下一镜的**声音**先出来，画面后到（波形像 J）；L-cut = 当前镜的画面已切走，
**声音**还拖着（波形像 L）。功能：转场如丝般顺滑，观众"被声音牵着走"。
**Remotion 实现**（极其简单，Sequence 错帧即可）：
```tsx
{/* J-cut：s2 的旁白提前 20 帧进入，画面还在 s1 */}
<Sequence from={O2 - 20} durationInFrames={S2 + 20}>
  <Audio src={staticFile('audio/s2.mp3')} />
</Sequence>
<Sequence from={O2} durationInFrames={S2}><Scene2/></Sequence>
```
**规范**：章节转场默认用 J-cut（旁白先行 0.5–0.8s）；L-cut 用于"余音"（结论句的尾音拖到下一镜的空镜上）。

## 六、景别递进公式：科普短片每幕的镜头模板

**公式**：**远景建立 → 中景叙事 → 特写强调 → 拉回远景收束**。
这是纪录片用了上百年的"呼吸循环"：把观众带进来（远）、讲清楚（中）、扎一刀（特）、
放出去（远）。每幕 10–15 秒切 4–6 个镜头，单镜头 1.5–4 秒。

### 模板 A：标准叙事幕（12–15 秒，5 镜）

```
[ELS 3.5s 慢推] → [MS 3.5s 横摇/跟] → [CU 2.5s 冲击变焦] → [ECU 1.5s insert静帧] → [WS 3s 拉]
 建立          叙事              强调              细节证据              收束
```

### 模板 B：快节奏蒙太奇（8–10 秒，4 镜，数据爆发/时代加速段）

```
[WS 2s 推] → [CU 2s 推] → [CU 2s 摇] → [ELS 2.5s 拉]
```
单镜 ≤2.5s，全部硬切，配甩镜音效。**同一能量级不超过 3 个连续镜头**后必须接一个慢镜呼吸。

### 模板 C：哲思/结论幕（12–15 秒，3 镜，慢）

```
[ELS 5s 极慢推 1.0→1.05] → [MS 4s 静止+粒子] → [WS 5s 极慢拉]
```
少切、慢运镜、长留白。结论句说完后，留 1–1.5 秒纯画面再黑场——让观众"登记"情绪。

### 分镜脚本新增列（STORYBOARD.md 每幕必须填）

| 列 | 说明 |
|---|------|
| 镜头# | 本幕第几个镜头 |
| 景别 | ELS/WS/FS/MS/MCU/CU/ECU |
| 角度 | 平视/仰角/俯角/鸟瞰/荷兰角（默认平视可省略） |
| 运镜 | 推/拉/摇/移/跟/静 + 参数（起止 scale、方向、时长） |
| 时长 | 秒（= 帧/30） |
| 画面 | AI 图描述 + prompt 关键词（含景别词、角度词、构图词、运动方向） |
| 剪辑点 | 硬切/J-cut/match cut/甩镜，与上一镜的衔接方式 |
| 旁白对位 | 这句旁白落在哪几帧 |

## 七、反模式：7 个镜头语言错误

| # | 错误 | 为什么错 | 修正 |
|---|------|----------|------|
| 1 | **跳轴**：火车上一镜向右、下一镜向左 | 观众以为火车掉头，空间感崩塌 | 分镜表定死每幕 `dir`，生图 prompt 写死方向，取景/粒子/转场全部对齐 |
| 2 | **景别跳跃过大**：WS 直切 ECU | 观众"找不到北"，以为换了场景 | 中间加一级（WS→MS→ECU），或用一镜内的 crash zoom 连起来 |
| 3 | **运镜方向混乱**：推→拉→摇随机组合 | 情绪线断裂，像晕船 | 相邻运镜只许"延续"（推→更推）或"有理由的反转"（推→拉=释然）；定一张运镜方向表 |
| 4 | **每个镜头都推镜** | 推镜贬值，等于没推；观众麻木 | 推镜留给"观点时刻"；日常用摇/静/跟；全片推镜 ≤40% 镜头 |
| 5 | **同景别连切**：三个 MS 连切同一主体 | 像 PPT 翻页，违反 30° 规则 | 换景别（MS→CU）或换角度（平视→仰角）再切 |
| 6 | **荷兰角/鸟瞰/手持滥用** | 特殊语法用多了就不是特殊了 | 荷兰角全片 ≤2 次，手持只给灾难/战争段，鸟瞰只给地理/格局段 |
| 7 | **主体永远居中 + 视线撞墙** | 呆板，人物像在"顶"着画面边缘 | 三分法 + 视线方向留白；居中只给对称式构图 |
